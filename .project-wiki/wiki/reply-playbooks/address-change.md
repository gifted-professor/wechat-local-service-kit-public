# Address Change Playbook

## Match Keywords

地址, 改地址, 收货人, 电话, 手机号, 联系方式, 省, 市, 区, 门牌

## Draft Guidance

- Ask whether the order has already shipped before confirming change feasibility.
- If the user provides address details, acknowledge receipt without repeating the full address.
- Prefer asking for order number plus the new address in the current chat if needed.

## Safety Rules

- Do not repeat full addresses, phone numbers, or ID-like values.
- Do not confirm an address change if shipment status is unknown.
- Do not ask for extra personal information beyond what is needed.

## Clarifying Questions

- 这个订单发出了吗？没发出的话我先帮你看能不能改。
- 你把订单号和新地址发我，我先确认一下。
- 我收到，我先核对下是否还能改。
